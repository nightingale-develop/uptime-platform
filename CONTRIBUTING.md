# Contributing

Follow [local development](docs/development.md) to build the application and run
checks through the Makefile.

Keep changes focused. Before submitting a pull request, run:

```bash
make format
make lint
make test
```

Explain what changed, why it was needed and how it was verified. Use the
[pull request template](.github/pull_request_template.md).

Commit prefixes: `feat:`, `fix:`, `refactor:`, `test:` and `docs:`.
