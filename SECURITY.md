# Security Policy

## Supported Versions

Uptime Platform is under active development. Security fixes are provided for the latest released version.

| Version | Supported |
| ------- | --------- |
| 1.2.x   | ✅ |
| < 1.2   | ❌ |

Only the latest release line is actively supported.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting or Security Advisory feature for this repository whenever possible.

When reporting a vulnerability, please include:

- A description of the issue
- Steps to reproduce it
- The affected version
- The potential impact
- Any suggested fix or mitigation, if available

Reports will be reviewed as soon as possible.

If the vulnerability is confirmed, a fix will be prepared and released before public disclosure whenever practical.

If the report is determined not to be a security issue, the reason will be explained to the reporter.
